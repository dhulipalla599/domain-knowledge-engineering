# Domain Knowledge for Full Stack Engineers

Most engineers can build a microservice. Far fewer can explain **why** a bank holds a payment for review, **what** an insurance underwriter actually decides, or **how** a hospital knows your coverage before you see a doctor.

This handbook closes that gap. Every page takes one business capability and walks it from a five-year-old's explanation all the way to data models, APIs, events, code and cloud deployment.

## How each page is organized

1. **Explain it like I'm five** - the idea in one analogy
2. **Business view** - overview, real example, stakeholders, key terms, process flow, rules
3. **Technical view** - business-to-system mapping, architecture, data model, APIs, events, backend and frontend code, cloud deployment, non-functional requirements
4. **Career view** - AI opportunities, common pitfalls, interview questions from junior to architect
5. **Practitioner notes** - real-world additions from the maintainers

Code snippets have **Java**, **Python** and **Node.js** tabs wherever it makes sense. Pick one and every snippet on the page follows.
